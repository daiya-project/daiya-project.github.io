Privacy Policy — Personal Agent CLI

Personal Agent CLI is used only by its owner with their own Google account.

Data accessed through Google APIs is processed only on the owner's computer. It is not sold, shared with third parties, or sent to any server operated by this app. OAuth tokens are stored in the owner's local macOS Keychain.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
